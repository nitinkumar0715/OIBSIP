BMI Calculator

Description

A simple Python-based BMI Calculator that calculates a person's Body Mass Index (BMI) based on their height and weight.

Features

- Calculates BMI easily
- Takes height and weight as input
- Displays the calculated BMI
- Shows the BMI category
- Simple and user-friendly

Technology Used

- Python

How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run the BMI Calculator Python file.
4. Enter your height and weight.
5. The program will calculate and display your BMI.
